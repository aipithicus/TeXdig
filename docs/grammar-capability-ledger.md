# Parent Grammar Capability Ledger

This ledger bounds the fourteen grammar files in the authoritative archaeology snapshot `20260831_115026`. It records what may be transferred, which code interprets each grammar's output, which parent tests remain useful as correlated oracles, what authority the syntax rests on, and how failure or recovery currently behaves. A row is an intake contract, not evidence that the capability has already landed in TeXdig.

The snapshot rows are the content authority for this study. The surveyed parent revisions were latex-utensils `641a665b298260bd0f5a67ce5e7ec6d233b44043` and unified-latex `3c1350edbc8f13ccfbbd5d96919391fefa4d268d`; the latter live checkout had an unrelated local modification, so its commit alone is not substituted for snapshot identity. Both parents are MIT-licensed and attributed in [`NOTICE`](../NOTICE).

Parent agreement is correlated evidence: the two core parsers share grammar ancestry, and the rest of each test corpus is producer-shaped. TeXdig records each observation independently and joins it with mechanics laws and gauntlet-derived properties; no row directs TeXdig to copy a parent result silently.

## Cross-cutting admission gates

Every port must satisfy all of these before its row can move from `ledgered` to `implemented`:

1. The generated parser has an explicit start-rule list and `unknown`-free typed facade; no consumer imports generated code directly.
2. Productions, interpreter branches, parent cases, authority, and recovery outcomes form one feature table. A production with no consuming branch or a consuming branch with no production is a visible disagreement.
3. Accepted source is represented by exact byte spans. Unsupported or malformed material becomes typed residue with diagnostics; strict mode rejects that same recorded residue rather than following a separate parse path.
4. Realization slices the original snapshot and reproduces every byte. Comments, whitespace, separators, duplicates, line endings, Unicode, and malformed bytes are never reconstructed from normalized strings.
5. Parent outputs are stored as independent, lineage-labeled observations. A divergence is classified as a TeXdig defect, a parent defect, or an explicit policy difference.
6. Timeout checks occur during repeated parser work, not only before or after the generated call, and timeout is a typed outcome.

## Core lexical fault lines

The merged core grammar must make the F7 choices observable rather than inheriting either parent's bias:

- command-name recognition uses explicit normal, at-letter, and expl3 state runs;
- `*` remains its own token unless a later signature-bearing consumer absorbs it;
- `^` and `_` remain ordinary text-mode tokens outside a licensed math/expl3 regime;
- `\par` remains an explicit control word and never becomes whitespace;
- verbatim is the first consumer that requires state-run transition evidence (RD-17);
- dense per-byte masks remain deferred until a consumer branches on them (RD-16).

The fourteen rows above are complete as an intake ledger. Their implementation schedules intentionally differ: G01–G03 and G05–G11/G13 are Phase 3 candidates, G12 is demand-gated, G08 belongs to Phase 4b semantics, G14 to typography/projections, and G04 to the Phase 8 compile adapter.
